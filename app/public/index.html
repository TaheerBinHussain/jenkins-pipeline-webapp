CI/CD Pipeline

Automated pipeline triggered on every Git push — from code commit to production deployment with zero manual steps.

🐳

Docker Containerized

Application is packaged as a Docker image and pushed to a container registry, ensuring consistent builds across all environments.

🔵🟢

Blue-Green Deployment

Zero-downtime deployments using blue-green strategy — new version is tested in the green environment before traffic is switched.

🔁

Rolling Deployment

Instances are updated gradually in a rolling fashion, maintaining availability throughout the deployment process.

↩️

Rollback Strategy

Automatic or manual rollback to the previous stable Docker image version in case the health checks fail after deployment.

🧪

Automated Testing

Jest unit tests run automatically in the pipeline's Test stage — the build fails fast if any test or coverage threshold is missed.
